# Normal vs Abnormal Image Classification

Binary image classification pipeline built for a computer vision coding test.

## Pipeline
1. **Dataset** – synthetic grayscale images in two classes: `normal` and `abnormal`
   (`dataset/normal/`, `dataset/abnormal/`). Generated by `generate_dataset.py`.
2. **Preprocessing** – Gaussian Blur (noise reduction)
3. **Edge Detection** – Canny edge detector
4. **Feature Expansion** – HOG (Histogram of Oriented Gradients) descriptor computed
   on the edge map, turning each image into a rich feature vector
5. **Train/Test Split** – 60% train / 40% test (stratified)
6. **Classifier** – SVM (linear kernel)
7. **Performance Measures** – Accuracy, Precision, Recall, F1-score, Confusion Matrix

## How to run

```bash
pip install -r requirements.txt

# Step 1: generate the dataset (already included, but can be regenerated)
python generate_dataset.py

# Step 2: run the full classification pipeline
python main.py
```

## Output
- Console: dataset summary, train/test split sizes, and all performance metrics
- `confusion_matrix.png`: saved confusion matrix plot

## Project Structure
```
cv_project/
├── dataset/
│   ├── normal/        # 60 synthetic "normal" images
│   └── abnormal/      # 60 synthetic "abnormal" images
├── generate_dataset.py  # creates the synthetic dataset
├── main.py               # full pipeline (preprocess -> edges -> features -> train -> evaluate)
├── requirements.txt
└── README.md
```

## Notes
- Images are synthetic (programmatically generated) so the project is fully
  self-contained and reproducible without needing an external dataset.
  To use a real dataset instead, just replace the contents of
  `dataset/normal/` and `dataset/abnormal/` with your own images (any format
  readable by OpenCV) — no code changes are required.
